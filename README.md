# EngineerOS Core

Build EngineerOS, a modern responsive engineering student ecosystem with the tagline “Learn. Build. Practice. Grow. Get Hired.” Treat the provided specification as the product vision, but implement a genuinely usable Phase 1 MVP first rather than a static mockup: secure authentication, student onboarding, personalized dashboard with Today’s Mission, progress and Next Best Action, course/learning system, Programming Academy, Linux Academy, DSA area, Daily Tasks, and an AI Mentor interface. Make the design feel like an intelligent engineering operating system, not a generic LMS. Create scalable, modular data architecture and admin-ready content patterns so branches, courses, skills, roadmaps and tasks can expand later. Include clear routes and working navigation for planned areas, and label external integrations or unavailable functionality honestly. Prioritize accessibility, responsive mobile-to-desktop design, dark/light mode, privacy-conscious student profile controls, and a polished dashboard-driven UX where students always know what to do next. Do not fake live jobs, certifications, external APIs, or code execution. Use the user’s detailed EngineerOS specification as the authoritative feature blueprint for later phases.
